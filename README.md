# BauServiceMD

Static multilingual website for the independent renovation craftsman Dmytro Mykhavkiv, serving Frankfurt am Main and the surrounding area.

Built with semantic HTML, separate CSS files and a small progressively enhanced JavaScript file. No database, trackers, third-party fonts or embedded maps.

## Languages

- Ukrainian: `uk/`
- German: `de/`
- English: `en/`

## Update pages

Run `python3 build.py` to regenerate the committed HTML pages. Edit the generator for shared layouts and translations; edit `assets/css/` for styling. GitHub Pages publishes the root of `main` directly; no framework or package installation is needed.

## Contact form

The form opens a prepared email draft in the visitor's email application. It does not submit messages to a server. WhatsApp, telephone and email links provide direct alternatives.

## Content

Generated photographs are labelled as illustrative. They must not be presented as completed client projects. Replace them with owner-approved project photographs when available. The legal pages clearly identify missing owner information and need owner review before use as final legal notices.
